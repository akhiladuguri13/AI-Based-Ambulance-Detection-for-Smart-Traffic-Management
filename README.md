🚑 Ambulance Detection System using Deep Learning

This project presents an intelligent ambulance detection system built using deep learning and computer vision techniques. The model is designed to accurately identify ambulances from input images, enabling faster and smarter decision-making in traffic management and emergency response scenarios.

The system utilizes a pre-trained convolutional neural network (CNN), specifically a ResNet-based architecture, to extract meaningful features and perform high-accuracy classification. A user-friendly web interface is developed using Streamlit, allowing users to upload images and instantly obtain detection results.

To improve efficiency and deployment readiness, the model has been optimized using half-precision (FP16), reducing its size while maintaining strong performance.

🔑 Key Highlights
1. Automated ambulance detection using deep learning
2. ResNet-based model for high accuracy
3. Streamlit-powered interactive web interface
4. Optimized model size using FP16
5. Fast and efficient inference

🛠️ Technologies Used
1) Python
2) PyTorch & Torchvision
3) Streamlit

🎯 Applications
